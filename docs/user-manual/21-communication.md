# 交流与讨论

> 路径: `/communication` 与 `/communication/new`

内部交流广场。支持板块(类目)+ 帖子 + 评论的多层结构,适合跨部门的轻量协作。

## 板块结构

| 层级 | 说明 |
|------|------|
| 一级板块 | 部门、主题(可由管理员配置) |
| 二级板块 | 同一板块下的子话题 |
| 帖子 | 一个主题讨论 |
| 评论 | 帖子下的多轮回复,支持嵌套 |

## 帖子能力

- 富文本 / Markdown 双模编辑
- `@` 提及用户或部门,被提及者收到通知
- 附件上传(自动归档到文档库,带链接)
- 表情、点赞、收藏
- 编辑历史可查,删除走软删除(管理员可恢复)

## 订阅与通知

- 关注板块:新帖推送
- 关注帖子:新评论推送
- `@` 提及:实时通知
- 默认仅在工作时间(08:00 - 20:00)推送紧急通知,可在个人资料调整

## 与其他模块联动

- 帖子可关联试验/项目/合规项,被关联项详情页有「相关讨论」入口
- 文档库的文档可一键「分享到讨论」,自动带版本号与摘要
- 智能助手可在讨论中被 `@`,回答自动以另一条评论呈现

## 权限

| 角色 | 权限 |
|------|------|
| 普通员工 | 浏览、发帖、评论自己可见板块 |
| 板块管理员 | 管理本板块帖子、置顶、加精 |
| 总管理员 | 全部 + 删帖 + 板块管理 |

## 注意事项

- 软删除不释放附件,文档库默认保留 30 天后清理
- 富文本支持图片直传,但单文件 ≤ 5 MB
- 大量 @ 提及时(>20 人),系统提示"可能打扰同事"
