# 公告

> 路径: 对应前端菜单「公告」入口

公告是企业内部最高优先级的信息发布渠道,常用于紧急通知、政策更新、节假日安排等。

## 主要功能

### 1. 查看公告
- 顶部滚动条显示"置顶"和"紧急"公告
- 列表按发布时间倒序,可按"生效日期"过滤
- 已读 / 未读一目了然,管理员可看每条公告的已读率

### 2. 发布公告(管理员 / 经理)
- 点击右上角「+ 发布」
- 必填项: 标题、生效日期、优先级(普通 / 重要 / 紧急)
- 可选: 富文本内容、附件、生效期、可见范围(全员 / 部门 / 角色)
- 在页面上新建的公告保存后**立即发布**并通知全员;草稿目前只能由智能助手起草(见下文「智能助手起草的草稿」)

### 3. 编辑与撤回
- 编辑公告会保留历史版本,可在详情页"版本"中查看
- "撤回"操作仅对尚未被全员读完的公告有效
- 撤回后会在所有用户通知中心留痕

### 4. 富文本能力
- 标题分级、列表、表格
- 图片直传(≤ 5 MB)
- 嵌入附件链接(自动归档至文档库)
- Markdown 与富文本双模切换

## 已读追踪

| 指标 | 含义 |
|------|------|
| 已读率 | 该公告被目标用户中已读的比例 |
| 读完时间分布 | 用户阅读完公告耗时直方图 |
| 未读名单 | 仅管理员可见,可一键"催促未读" |

## 离线与内网

- 公告图片自动归档到 paperless,带访问链接
- 公告不会因服务重启丢失(已固化为业务数据)

## 注意事项

- 紧急公告发布后会强制弹窗,用户必须主动关闭(可在 5 / 30 / 60 秒后自动消失)
- 撤回操作会生成审计日志
- 删除公告会物理删除所有已读记录(谨慎操作)

## 智能助手起草的草稿(2026-09 新增)

管理员或 HR 可以让智能助手起草公告,例如"起草一个国庆放假安排的公告"。

1. 助手给出确认卡片,核对标题和正文后点「确认执行」。
2. 公告以**草稿**保存:**不会通知任何人**,普通员工在公告页也看不到。
3. 到「控制面板 → 公告管理」,草稿显示「草稿」标签,可以编辑、删除或点「发布」。
4. 点「发布」后公告对全员可见,并按正常流程通知全体用户(起草人本人除外)。

说明:

- 只有管理员和 HR 能起草、查看和发布草稿;助手不能替你发布。
- 同一草稿只能发布一次,重复点击会提示"该公告已发布"。
- 草稿发布前,可在助手的确认卡片上点「撤销」删除它;已发布或已被修改的草稿不能再撤销。
- 公告列表和首页「最新公告」按发布时间排序。

## 最近改进（2026-07 P0 批次）

### 公告发布即时通知

发布新公告后,**所有其他登录用户**会在 5 秒内在右上角铃铛处看到红色未读角标(NotificationBell)。收到通知后:

1. 点击铃铛下拉 → 找到对应 `type='announcement'` 条目
2. 点击跳转公告详情(标题与正文一并送达通知 payload)
3. 已读后下次登录不再弹角标(可豁免)

### 创建入口直达(2026-07 修复)

历史上"发布新公告"按钮偶尔跳转到 `/new`,提示 404。**已修复**为指向 `/control-panel/announcements/create`,点击直达编辑器。

### 编辑模式正确识别(2026-07 修复)

点击"编辑"进入 `/edit/{id}`,前端正确切到"编辑"模式(历史曾因路由参数名错位而永远显示"新建"表单)。
