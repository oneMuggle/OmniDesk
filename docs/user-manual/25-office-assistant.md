# Office 助手 / 文件分析

> 路径: `/office-assistant`、`/file-analysis`

利用 AI 把 Office 文档(Word/Excel/PPT/PDF)解析为可检索、可问答的结构化数据。

## 适用场景

- "这份 100 页的 PDF 里关于 X 主题的章节在哪?"
- "把这些 Excel 按部门拆分,并生成统计图"
- "把这张 PPT 里的图片全部导出来"
- "把这份合同的关键条款摘要 + 风险高亮"

## 使用步骤

### 1. 上传文件
- 拖拽文件到 `/file-analysis` 或在「Office 助手」中选择
- 支持: PDF(扫描件支持 OCR)、DOCX、XLSX、PPTX、TXT、MD
- 单文件 ≤ 50 MB;批量上传一次最多 20 个

### 2. 选择任务
- 「摘要」- 输出 200 字内的核心要点
- 「问答」- 进入对话模式,基于文档内容回答提问
- 「抽取」- 按用户定义的字段(姓名/日期/金额等)输出结构化 JSON
- 「翻译」- 整篇或选定段落翻译
- 「对比」- 跨文档差异比对

### 3. 输出
- 处理进度实时显示
- 完成后可在「历史记录」中查看、导出(原格式 / Markdown / JSON)

## 文件去向

- 上传的文件和解析结果会写入「文档库」的 paperless 存储,带源文件链接
- 单文件保存期限默认 180 天,可在「系统设置」延长
- 高敏文件可标记「阅后即焚」,到期自动清理

## 离线与内网

- 文件分析任务通过本地「文件处理」(file_processing) 服务 + MinerU / LibreOffice 完成解析
- LLM 调用使用本地 Ollama,数据不出网
- 详细架构见 [技术手册 - 预留编号 36](../technical/README.md)

## 性能与限制

- 大型 PDF(>200 页)解析时间约 1-3 分钟,请勿重复提交
- OCR 精度依赖于扫描分辨率(推荐 ≥ 300 dpi)
- 加密 PDF 需先在本地解密后上传

---

## 当前真正支持的操作（2026-07 P0 收敛）

> **重要:** 上文 §"选择任务"中列出的"摘要 / 问答 / 抽取 / 翻译 / 对比"为**未来规划**,**当前版本(2026-07)实际只支持以下 3 个能力**:
>
> | 操作 | 说明 |
> |---|---|
> | **proofread** | 校对文本中的错别字、语法、标点 |
> | **translate** | 整篇或选定段落翻译 |
> | **polish** | 把口语化文本润色为更专业表达 |
>
> 后端实现 [`office_assistant/views.py` 的 `ALLOWED_ACTIONS = ('proofread', 'translate', 'polish')`](https://github.com/.../omni_desk_backend/office_assistant/views.py),其他 action 会返回 **HTTP 400** + `detail="unsupported action"`,前端会弹出明确提示。

### 为什么不一口气支持所有操作?

- 当前文档解析通道(MinerU)对"摘要 / 抽取"还没做过鲁棒性测试
- LLM Ollama 本地部署对"长文档问答"上下文窗口受限
- **优先收敛可用范围**,避免用户尝试后默默失败

### 何时会扩展?

- P1 计划:加入 `summarize`(摘要)、`extract_keywords`(关键词抽取)
- 届时同步更新前端"任务选择面板"和本节文档

### 误点击了不支持的操作怎么办?

系统会弹出明确的错误提示(不再是模糊 500):

> "暂不支持该操作。当前支持:proofread / translate / polish。请在右侧任务面板选用。"

如确需该能力,请联系管理员或提交 issue,纳入 P1 计划。
