# 智能助手使用指南

> 📅 **2026-09 更新(S2)**:AI 入口收敛。智能助手页顶部分为「对话 / 任务 / 应用」三个标签,Dify、Ragflow、Office 助手、文件分析都在「应用」里;统计与审计移到控制台「AI 管理」。任意页面右下角的悬浮按钮可打开 AI 抽屉,会带上当前页面的记录作为上下文。旧地址会自动跳转。
>
> 📅 **2026-08-06** — 新增 §2.13:"直接看文件 / 问表格 / 生成文档"(智能助手聊天内直接上传 .docx/.pdf/.xlsx/.pptx/.txt/.md/.csv,生成 .docx 通过下载卡片交付)。同步最新模块功能。

## 1. 进入智能助手

在左侧菜单中找到 **"AI 助手 → 智能助手"**,点击进入。页面顶部有三个标签:

| 标签 | 地址 | 内容 |
|---|---|---|
| 对话 | `/smart-assistant` | 聊天界面(默认) |
| 任务 | `/smart-assistant/tasks` | 多 Agent 协作任务:提交复杂目标,查看进度、人工介入 |
| 应用 | `/smart-assistant/apps` | Dify 应用、Ragflow 聊天、Office 助手、文件分析 |

在其他页面也可以点右下角的悬浮按钮打开 AI 抽屉,不用离开当前页面。

聊天界面支持:
- **流式打字效果**:AI 回答逐字显示,无需等待完整生成
- **多轮对话**:自动保存上下文,后续提问可引用前文
- **Markdown 渲染**:回答中的代码、表格、列表自动格式化

### 2.6.1 公司公告(`announcement_query`,阶段 3 新增)

通过 `communication.Post` 表查询已发布、未过期、未归档的公告(最多 10 条最新)。

**典型问题**:
- "这周有什么公告"
- "本周例会通知"
- "最近的安全检查通知"
- "公司放假安排"

**返回**: 公告卡片,显示标题(过期标橙色 tag)、发布人、发布日期、内容(200 字截断 + `...`)。

### 2.6.2 合规问题(`compliance_query`,阶段 3 新增)

通过 `compliance.ComplianceIssue` 表查询待处理/处理中的合规问题,按业务优先级排序(紧急 > 高 > 中 > 低)。

**典型问题**:
- "待整改"
- "张三还有几条待整改"
- "紧急的合规问题"
- "即将到期的整改"
- "签字相关的问题"

**返回**: 合规卡片,显示问题类型 + 严重程度 tag(红/火山/橙/灰)+ 状态 tag(已解决=绿/进行中=蓝)、所属项目、截止日期、问题位置、描述。

### 2.6.3 内网外链(`external_link_query`,阶段 3 新增)

通过 `external_integration.ExternalLink` 表查询公司内网工具导航(VPN、Jira、Confluence 等)。

**典型问题**:
- "公司 VPN 怎么登录"
- "Jira 怎么打开"
- "所有内网工具"
- "研发相关链接"
- "SSO 登录地址"

**返回**: 外链卡片,显示名称(可点击,SSO 启用时跳 SSO 端点)+ 紫色 SSO 标签、分类、地址、说明。

### 2.11 多工具复合查询

智能助手支持**一次提问触发多个工具**,例如:

- "张三今天的排班和他最近的项目"→ 人员 + 排班 + 项目
- "本周公告和合规检查计划"→ 公告 + 合规

回答时会合并多个工具的结果,标注数据来源。

### 2.12 不支持的内容

- ❌ 文献搜索(CNKI / IEEE / PubMed)— 暂无授权,见 [技术手册 16 §6 Phase 9](../technical/16-smart-assistant.md)
- ❌ 实时网页搜索
- ❌ 图片/语音输入(P3 阶段评估)

### 2.13 直接"看文件 / 问表格 / 生成文档"(2026-08 阶段 1 新增)

> 在聊天输入框旁有 **📎 上传** 按钮,可以直接把 Office 文件丢给助手,无需先去知识库上传。

#### 支持的文件类型

- **文档**: `.docx`、`.pdf`、`.txt`、`.md`
- **表格**: `.xlsx`、`.csv`
- **幻灯片**: `.pptx`(只读)
- **单文件大小**: ≤ **10 MB**
- ❌ **暂不支持**: `.doc` / `.xls` / `.ppt` 老格式、加密 PDF、纯扫描件 PDF(无 OCR)

#### 三类典型用法

**A. 看文件后问答**(读场景,无需确认)

```
1. 点击输入框旁 📎 → 选 "采购合同 2026Q3.docx"
2. 提问:"这份合同的有效期是?违约金条款怎么写?"
3. 助手基于全文直接回答(SSE 流式)
```

支持的查询:关键条款摘要、风险高亮、跨章节引用、信息定位(章节/页码)。

**B. 问表格**(读场景,统计/数据问答)

```
1. 上传 "8 月销售数据.xlsx"
2. 提问:"按部门统计总金额,并列出前 5 名"
3. 助手自动调用 Spreadsheet 工具,返回 Markdown 表格 + 文字摘要
```

支持:简单聚合(sum/count/avg)、groupby 统计、按条件筛选、自然语言提问数据规律。

**C. 生成文档**(写场景,**需要确认**,聊天中会出现确认卡片,见 [2.14](#214-让助手帮你办事需要确认的写操作2026-09-新增))

```
1. 描述:"基于公司换班制度,帮我生成一份请假单"
2. 助手先返回草稿(标题/段落/表格/变量)
3. 在确认卡片中核对内容
4. 点「确认执行」后,助手生成 .docx,并在卡片中展示 ⬇️ **下载卡片**
5. 点击卡片下载(链接 10 分钟内有效)
```

注意:

- **下载链接有时效**: 10 分钟,过期请重新让助手生成
- **生成内容不进会话历史**: 下次提问看不到上次生成的文档
- **不会覆盖你的磁盘**: 仅写服务器临时目录,下载后自动清理

#### 常见问题

**Q: 上传后助手说"未提取到文本内容"?**

A: 可能是纯扫描件 PDF、纯图片 PPT、无文字 PDF。这种情况需要先 OCR(MinerU 通道将在阶段 2 接入)。

**Q: 上传 10MB 以上文件被拒?**

A: 前端会立即提示,后端也兜底校验。如确需更大,联系管理员放宽 `MAX_OFFICE_UPLOAD_SIZE`(不推荐)。

**Q: 下载链接点击后提示"链接已失效"?**

A: 下载链接 10 分钟过期,或已被使用。让助手重新生成一次即可。

**Q: 生成的文档可以二次编辑吗?**

A: 阶段 1 仅生成简单版式(标题/段落/表格);复杂版式请下载后用 Word 调整。阶段 2+ 将引入 docxtpl 模板系统。

### 2.14 让助手帮你办事:需要确认的写操作(2026-09 新增)

助手可以替你完成一部分修改数据的操作。**任何修改都要你在确认卡片上点「确认执行」才会生效**,助手不会自己动手。

| 示例说法 | 能做什么 | 谁能做 | 能否撤销 |
|----------|----------|--------|----------|
| "把关于报销的通知都标为已读" | 将本人的通知标为已读(一次最多 50 条) | 本人 | 可以 |
| "帮我订明天下午两点到三点的三楼会议室,开周会" | 预约会议室,自动检查时段冲突 | 有会议室模块权限的用户 | 可以(撤销即删除该预约) |
| "把我明天的周会预约取消" | 取消**本人的、尚未开始的**预约 | 本人(管理员也只能取消自己的) | 可以(撤销即按原时段重新预约) |
| "把合规问题 12 改成整改中" | 修改合规问题状态 | 项目负责人或管理员 | 可以 |
| "帮我记一条备忘:周五交报告" | 新建 / 修改备忘录 | 本人 | 可以 |
| "起草一个国庆放假安排的公告" | 起草公司公告,**只保存为草稿**,不会通知任何人;需在「公告管理」页由人发布 | 管理员或 HR | 可以(草稿未发布、未修改时) |
| "下周二 9 点到 17 点给某研究所安排振动试验,责任人张三,用振动台 A" | 创建试验日程(时间段、责任人、设备);如与其他试验在同一时段共用设备或责任人,卡片上会提示冲突,但仍可确认 | 管理员或 HR | 可以(试验未被修改时) |
| "帮我生成一份请假单" | 生成 Word 文档 | 所有人 | 不涉及 |

**确认卡片上会写清楚:**

- 要做什么、改哪一条(例如"三楼大会议室 · 10-08 14:00–15:00")
- 改动前后的值(例如"状态:待处理 → 整改中")
- 影响多少条,以及具体是哪几条
- 你凭什么权限能做这件事(例如"项目负责人")
- 是否可以撤销;删除类操作会用红色标出

**怎么操作:**

1. 在对话中说出你要办的事,助手会先查清楚,然后给出确认卡片。
2. 核对无误,点「确认执行」;不想做了,点「取消」,不会有任何修改。
3. 执行成功后卡片会显示结果;可撤销的操作会出现「撤销」按钮。

**注意:**

- **只有点按钮才算确认。** 在对话框里输入"确认""好的"只是普通聊天,不会执行任何操作。
- 确认卡片有有效期,过期后请重新让助手发起;每张卡片只能确认或取消一次。
- 从确认到执行之间,如果数据已被别人改过(例如会议室时段被人抢先预约、合规问题状态已变),助手会停止执行并告诉你原因,请重新发起。
- 卡片上的黄色提示(例如"时段冲突""不会通知任何人")只是提醒,不会阻止确认,请看清后再决定。
- 创建试验时,责任人要写全名;有重名时助手会列出候选,请到试验日程页手动选择。
- 撤销同样会检查当前状态:如果之后又有人改过这条数据,撤销会失败并说明原因,不会覆盖别人的修改。
- 全屏智能助手和右下角的助手抽屉都支持确认卡片。
- **删除备忘录**默认不开放给助手,需要管理员在服务器配置中开启(`SMART_ASSISTANT_ENABLE_DESTRUCTIVE_TOOLS=true`)。

## 3. 对话管理

### 3.1 新建会话

- 点击聊天界面左上角的 **"+"** 按钮创建新会话
- 新会话默认标题为前 50 字,可手动修改

### 3.2 切换会话

- 左侧侧边栏列出所有历史会话,按最近时间倒序
- 点击任意会话即可恢复上下文继续对话
- 搜索框支持按标题/内容关键词过滤

### 3.3 删除会话

- 在侧边栏右键点击会话 → 删除
- 或在会话详情页右上角点击删除按钮

### 3.4 反馈与重试

每条 AI 回答下方提供:
- 👍 点赞
- 👎 点踩(自动收集到训练反馈)
- 📋 复制
- 🔄 重试(相同问题重新生成)

## 4. 知识库管理

进入 **"AI 助手 → 知识库管理"** 页面。

### 4.1 上传文档

1. 点击 **"上传"** 按钮
2. 选择文件(支持 PDF / Word / Markdown / TXT)
3. 填写标题(必填)、分类(可选)、标签(可选)
4. 点击确认,文档进入"待解析"状态

### 4.2 状态流转

| 状态 | 含义 |
|------|------|
| 待解析 | 等待 Celery worker 处理 |
| 解析中 | Ragflow 正在向量化 |
| 已完成 | 可被 RAG 工具检索 |
| 失败 | 查看错误日志后可重试 |

### 4.3 删除文档

- 列表中点击删除 → 二次确认
- 删除时同步取消 Celery 任务与 Ragflow 中的索引

> ⚠️ 删除操作不可恢复,删除前请确认不再被引用。

## 5. 审计面板(管理员)

进入 **控制台 → AI 管理 → Agent 审计**(`/control-panel/ai/audit`,需管理员权限;旧地址 `/control-panel/smart-assistant/audit` 自动跳转)。

可查看:
- **总览卡片**:今日对话数、Token 消耗、费用估算、平均响应时间

- **工具成功率**:柱状图(各工具调用成功率)
- **每日用量趋势**:折线图
- **异常告警列表**:超时 / 失败 / 高额 Token
- **详情查询**:可按用户/时间/意图/关键词过滤

## 6. 统计页面

进入 **控制台 → AI 管理 → 使用统计**(`/control-panel/ai/stats`,需管理员权限;旧地址 `/smart-assistant/stats` 自动跳转)。

展示:

- 工具使用偏好
- 反馈统计(点赞/点踩比)

## 7. 常见问题

### Q1:提问后没反应?

- 检查浏览器 Network 面板,看 `/api/smart-assistant/chat/stream/` 是否正常返回
- 流式响应首帧需 1-3 秒,属正常(可联系管理员开启 TTFT 优化)

### Q2:回答不准确?

- 试用"换一种方式提问"
- 或直接联系管理员,管理员可在审计面板查看 LLM 完整 prompt 与 tool 输出,定位问题

### Q3:提示"请求过于频繁"?

- 单用户每分钟最多 30 次请求(系统限流)
- 等待 1 分钟后重试,或联系管理员调高限制(不推荐)

### Q4:工具没找到我要的信息?

- 工具返回 `found=False` 时,助手会尝试通用回答
- 通用回答可能不准确,建议:
  - 调整提问关键词
  - 检查知识库是否已上传相关文档
  - 联系管理员添加/调整工具

### Q5:对话历史丢失?

- 默认保留 30 天(可在系统设置调整)
- 删除会话不可恢复

### Q6:支持多语言吗?

- 当前主要为中文问答,英文支持有限
- 多语言切换在 P3 阶段评估

## 2026-09 更新(数字员工)

系统里有三位「数字员工」,按时间自动巡检,通过**站内通知**提醒你。它们只会**发起并请求确认**,不会替你直接修改数据。

| 数字员工 | 什么时候 | 做什么 | 默认 |
|---|---|---|---|
| 个人秘书 | 工作日 08:30 | 推送晨报:今天的备忘、今明两天的值班、今天的会议、待你同意的换班申请 | 开启 |
| 排班管理员 | 工作日 16:00 | 巡检未来 7 天排班。你值班那天还负责试验时,推荐一位接替人,请你确认是否发起换班申请 | 关闭,由管理员开启 |
| 合规专员 | 工作日 09:10 | 汇总你负责项目里 3 天内到期或已逾期的合规问题;为逾期或紧急的问题起草整改建议 | 关闭,由管理员开启 |

### 确认数字员工的建议

1. 通知铃铛里出现「待确认:……」的通知,点击后进入智能助手。
2. 页面上显示确认卡,写明是哪位数字员工发起的、要做什么、影响哪些内容、能否撤销。
3. 点「确认执行」才会执行;点「取消」则不做任何修改。
   - 确认换班建议:以你的名义向接替人发送换班申请,对方同意后才生效。
   - 确认整改建议:存为你的一条备忘录(到期日 09:00 提醒),可以撤销。
4. 待确认事项 48 小时内有效(换班建议不晚于值班当天),过期后需要重新发起。

### 管理员:启停与配额

控制台「AI 管理 → 数字员工」:

- 每位数字员工可以单独**启用 / 停用**,单独设置**每日动作配额**(通知和待确认事项的数量)和**每日 LLM 配额**。
- 动作配额用完后,当天剩余的提醒会跳过,并通知负责人;LLM 配额用完或调用失败时改用模板内容。这两种情况的运行状态都显示为「已降级」。
- 「立即运行」可以手动触发一次;「运行记录」显示最近 20 次运行和每一个动作的审计记录,管理员修改配置也会记录在内。
