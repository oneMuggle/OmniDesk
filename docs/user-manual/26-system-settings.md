# 系统设置

> 路径: `/system-settings`(管理员可见)

系统级开关、频道配置、缓存清理、AI Provider 配置等。仅管理员可见。

## 主要分区

### 1. 通用
- 站点名称、Logo、备案号
- 默认语言(中文 / English)、时区
- 注册策略(开放 / 邀请制 / 关闭)

### 2. 通知渠道
- 邮件 SMTP 配置(发件人、模板、SPF/DKIM 校验状态)
- Webhook 出口(单组织最多 5 个)
- 站内通知保留期(默认 90 天)

### 3. AI Provider
- Ollama / OpenAI / 智谱 / 私有 LLM Endpoint
- 模型下拉选择 + 健康检查
- 失败兜底(主 provider 失败时自动切到次 provider)

### 4. 智能助手
- 13 个工具的独立开关
- Hook 启用(PII 脱敏、超时熔断、审计)
- 滚动摘要阈值(token 数)
- 工具风险分级(read / write / destructive)审批链

### 5. 缓存与清理
- 智能助手会话缓存大小、过期
- 文档库 paperless 同步状态
- 智能助手统计缓存
- 「清空所有缓存」按钮(请在低峰时段操作)

### 6. 第三方集成
- paperless-ngx:URL、Token、健康状态
- RAGFlow:URL、健康状态、最近同步
- Dify:URL、API Key 显示前 4 后 4 位
- SSO(OIDC / SAML)配置

### 7. 审计
- 登录审计(90 天)
- 关键操作审计(增删改合规/试验/合规证据)
- 调用审计(LLM/Dify/RAGFlow)

## 危险操作

以下操作会二次确认:

- 「删除所有通知」- 需要二次确认 + 输入「DELETE」
- 「清空所有缓存」- 需要二次确认
- 「关闭某智能助手工具」- 需要输入原因,会通知该工具负责人

## 备份与导出

- 配置变更历史可在「系统设置 → 操作日志」中查看
- 一键导出当前完整配置(JSON,不含密钥)
