# 事件管理

> 路径: `/events`

「事件」不同于「试验」:试验是有计划、可长时间执行的项目,而事件是临时发生、需要快速跟进的事务(如异常、投诉、应急响应)。

## 事件分类

| 类别 | 典型场景 | 处理时限(SLA) |
|------|---------|--------------|
| 安全 | 实验室意外、辐射/生物安全 | 1 小时内首响应 |
| 设备 | 设备损坏、误操作 | 4 小时内首响应 |
| 合规 | 疑似违规、文件缺失 | 24 小时内首响应 |
| 流程 | 流程卡点、系统异常 | 48 小时内首响应 |
| 其它 | 临时事务 | 自定义 SLA |

## 事件生命周期

```
新建 → 分配 → 处理中 → 待复核 → 已关闭
                          ↓
                       重新打开(可选)
```

## 主要操作

### 登记事件
1. 点击「+ 登记」
2. 选择类别、填基本信息、上传证据(图片/视频/文档,自动归档到文档库)
3. 系统按类别默认分配处理人,也可手动指派

### 处理过程
- 每个事件有独立讨论区,所有参与人可见
- 可一键转派:通知原处理人与新处理人
- 关联试验/设备/合规:点击「关联」即可建立反向引用

### 关闭
- 处理人填写结案报告
- 复核人审核后关闭
- 所有附件、讨论、状态变更永久保留,可在「事件审计」中追溯

## 通知与升级

- 临近 SLA 时自动通知
- 超 SLA 后向事件类别负责人 + 管理员升级
- P0 级别事件自动创建合规追踪项

## 权限

- 任何员工都可登记事件
- 处理人、复核人由管理员或类别负责人配置
- 管理员可导出全量事件数据
