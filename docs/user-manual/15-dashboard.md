# 仪表盘首页

> 路径: `/`(登录后默认落地页)

仪表盘是你的"今日工作台",把所有待办和近期事件聚在一处,避免跳到多个页面查日程。

## 主要模块

| 模块 | 内容 | 操作 |
|------|------|------|
| **今日日程** | 当天排班、会议预约、试验节点 | 点击进入对应模块详情 |
| **待办事项** | 待审批、待签字、待复核 | 进入对应业务页处理 |
| **未读通知** | 最近 5 条站内通知 | 点开查看,或在通知中心标记已读 |
| **最新公告** | 当前生效中的公告 Top 3 | 进入公告详情或公告列表 |
| **我的备忘录** | 当天到期的提醒 | 直接完成或延期 |
| **快捷入口** | 文档库、智能助手、RAGFlow、Dify 收藏 | 一键跳转 |

## 个性化

- 拖拽卡片调整顺序
- 在「个人资料 → 首页布局」隐藏不常用的模块(计划中)
- 整体刷新按钮在右上角,自动刷新频率 5 分钟

## 注意事项

- 仪表盘只展示与你有权限的资源,不会泄漏他人数据
- 长期未登录会触发"上次登录提醒",异常 IP 登录会在通知中心告警
- 移动端会自动折叠为单列布局,功能不变
