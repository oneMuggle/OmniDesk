# 试验管理

> 路径: `/trials`(原名「事件管理」,后拆分为「试验」与「事件」两个模块)

试验管理贯穿一次科学试验从立项到归档的全过程,关联人员、设备、传感器、合规记录。

## 试验状态

| 状态 | 含义 | 允许的动作 |
|------|------|-----------|
| 草稿 | 尚未提交审批 | 编辑、删除、提交 |
| 待审 | 等待负责人/合规审批 | 撤回、催办 |
| 进行中 | 已批准并开始 | 添加阶段、记录数据、上传附件 |
| 暂停 | 临时冻结 | 编辑当前阶段、申请恢复 |
| 已完成 | 主要工作结束 | 归档、生成报告 |
| 已归档 | 不可变更,仅可读 | 查看、导出 |

## 主要操作

### 创建试验
1. 点击右上角「+ 新建」
2. 填写基本信息(标题、负责人、起止时间、合规关联)
3. 系统自动检查「负责人时间冲突」与「设备占用」
4. 提交后进入待审队列

### 阶段流转
1. 在详情页「阶段」选项卡新增/调整
2. 每阶段可关联:人员、设备、传感器读数、合规检查项
3. 阶段完成时强制要求「数据完整性自检」通过

### 关联合规
- 创建试验时可勾选需要遵守的合规项(如生物安全、辐射防护)
- 系统自动生成对应的合规追踪任务,见「[合规追踪](20-compliance.md)」

## 与其他模块的关系

- **排班**:阶段任务自动推送至负责人当日排班
- **设备**:占用状态实时反馈到设备管理
- **合规**:合规检查项独立追踪,逾期会通知负责人与合规员
- **文档库**:阶段数据附件自动同步到 paperless,标记「试验-XXX」

## 权限

| 角色 | 权限 |
|------|------|
| 试验负责人 | 创建、编辑本人负责的试验 |
| 试验成员 | 查看、上传数据 |
| 合规员 | 查看所有、审批合规相关阶段 |
| 管理员 | 全部权限 |
