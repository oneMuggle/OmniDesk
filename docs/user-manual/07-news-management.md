# 新闻管理

> 路径: 对应前端菜单「新闻」入口

新闻是相对低频、面向全员的知识性内容(如团建、技术分享、新人介绍)。与"公告"(即时性、强制阅读)不同,新闻更接近企业文化墙。

## 主要功能

### 1. 查看新闻
- 列表页:卡片式展示,可按分类(技术 / 文化 / 制度 / 通知)过滤
- 详情页:支持富文本阅读、点赞、收藏、评论
- 顶部"置顶"新闻滚动显示

### 2. 发布新闻(授权用户)
- 路径: 点击「+ 发布新闻」
- 必填项: 标题、分类、摘要(列表卡片显示)、正文
- 可选: 封面图、相关附件、相关项目 / 人物
- 支持保存草稿、定时发布

### 3. 编辑 / 删除
- 自己发布的可随时编辑(保留版本)
- 管理员可编辑任何新闻
- 删除走软删除(30 天内可恢复)

### 4. 互动
- 点赞与收藏数量公开
- 评论嵌套层级最多 3 层
- 提到(@)用户或部门会推送通知

## 分类管理(管理员)

- 系统的预置分类: 综合、技术、文化、制度、通知、其他
- 管理员可自定义分类、调整排序、控制可见角色

## 权限

| 角色 | 权限 |
|------|------|
| 普通员工 | 浏览、点赞、收藏、评论 |
| 授权编辑 | 浏览 + 发布 + 编辑自己发布的 |
| 管理员 | 全部权限 |

## 与公告的区别

| 维度 | 公告 | 新闻 |
|------|------|------|
| 时效 | 即时 / 重要 | 长效 |
| 阅读强制 | 是(紧急公告弹窗) | 否 |
| 已读追踪 | 是 | 否 |
| 适合场景 | 紧急通知、政策更新 | 团建、技术分享、文化建设 |

## 离线与内网

- 与公告一样,所有附件自动归档到 paperless
- 缓存策略: 列表缓存 5 分钟,详情缓存 1 小时

## 注意事项

- 同一新闻多次编辑只保留最近 5 个历史版本
- 删除评论需管理员操作,且保留原文记录
