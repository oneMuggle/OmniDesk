# 个人资料

> 路径: `/profile`

在这里管理你的账号基本信息、通知偏好以及绑定的员工档案。

## 基本信息

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| 头像 | ✅ | 上传图片(自动压缩到 ≤ 500KB) |
| 姓名/昵称 | ✅ | 真实姓名为锁定字段(由 HR 维护),仅可调昵称 |
| 邮箱 | ✅ | 修改后需重新验证(收确认邮件) |
| 手机号 | ✅ | 修改需短信验证码 |
| 密码 | ✅ | 独立入口,需要输入旧密码 |

## 通知偏好

- 站内通知:默认开启,无法关闭
- 邮件通知:可单独勾选(排班变更、公告、合规到期等)
- Webhook:仅对管理员可见

> 详细通知类型见「[通知中心](10-notifications.md)」。

## 关联员工档案

如果你同时是组织内的员工,在「我的信息 → `/me/personnel`」可查看由 HR 同步来的档案:
- 工号、部门、岗位
- 入职日期、合同状态
- 关联的排班/试验/项目

账号 ↔ 员工档案的绑定规则详见 [技术手册 § 26](../technical/26-personnel-user-association.md)。

## 安全建议

- 每 90 天修改一次密码
- 开启两步验证(若部署了 SSO,自动强制)
- 在「最近登录」中检查陌生会话,一键登出
