# 项目管理

> 路径: 对应前端菜单「项目管理」入口

项目管理用于跟踪跨部门的、有明确起止时间和目标的工作。每个项目可分解为任务、里程碑、关联人员与合规事项。

## 项目状态

| 状态 | 含义 |
|------|------|
| 草稿 | 尚未立项,仅创建者可见 |
| 待启动 | 已审批,等待启动日期 |
| 进行中 | 已经启动,正常推进 |
| 阻塞 | 有关键问题阻塞进展(必须填原因) |
| 已暂停 | 主动暂停 |
| 已完成 | 主要工作结束,等待归档 |
| 已归档 | 不可变更,仅可读 |

## 主要操作

### 1. 创建项目
1. 路径: 列表页 → 右上角「+ 新建项目」
2. 必填: 项目名称、负责人、起止日期、所属部门
3. 可选: 描述、关联合规项、关联试验、外部成员
4. 提交后自动进入审批流(由部门负责人 / 项目办审批)

### 2. 任务分解
- 项目下可建任务,任务可指派到个人,有截止日期
- 任务状态: 待办 / 进行中 / 待复核 / 已完成 / 已取消
- 看板视图(按状态列)与列表视图可切换

### 3. 里程碑
- 关键节点的标记,用于周报、月报统计
- 临近里程碑会通知负责人

### 4. 关联合规
- 创建项目时勾选合规项,系统自动生成追踪任务
- 关联文档: 上传附件到项目,自动同步至文档库并标记"项目-XXX"

## 报表与导出

- 项目周报: 自动汇总本周完成的任务、阻塞项、风险
- 项目月报: 进度、S-曲线、燃尽图
- 导出: PDF / Excel / CSV

## 权限

| 角色 | 权限 |
|------|------|
| 项目负责人 | 创建、编辑、负责审批任务 |
| 项目成员 | 查看、上传文档、完成任务 |
| 部门负责人 | 审批本部门项目 |
| 项目办 / 管理员 | 全权 |

## 与其他模块的关系

- **合规追踪**: 合规项独立追踪,见 [合规追踪](20-compliance.md)
- **试验管理**: 项目可分解到试验,试验可挂载到项目
- **文档库**: 项目附件走 paperless 通道

## 离线与内网

- 项目数据存储在 PostgreSQL,与业务其他数据共用一份备份
- 附件走 paperless,见 [技术手册 § 31](../technical/31-paperless-integration.md)
