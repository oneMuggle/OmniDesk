# Dify 应用

> 路径: `/dify-apps`

Dify 是一个开源的 LLM 应用编排平台。OmniDesk 通过对接 Dify,把团队内的 AI 应用统一入口,无需单独访问 Dify 控制台。

## 主要操作

### 浏览应用
- 顶部按类别过滤(聊天、Agent、工作流、文本生成)
- 每张卡片显示:图标、名称、最近调用次数、平均响应时长
- 点击进入详情,打开侧边抽屉运行

### 运行应用
1. 选中应用
2. 填入表单(若应用有输入字段)/ 直接对话
3. 流式响应,支持重新生成、复制
4. 历史会话在右侧列表,支持命名与归档

### 鉴权与配额
- 用户通过 OmniDesk 单点登录到 Dify
- 应用配额由 Dify 端配置:每用户/每应用/每组织
- 超额应用会显示「需申请」标签,走 OA 流程即可获得配额

## 应用管理(管理员)

- 应用接入:在 Dify 控制台获取 API Key + Endpoint,在 OmniDesk 后台注册
- 权限控制:可按角色启用/禁用特定应用
- 数据同步:每 5 分钟拉取应用列表缓存到 OmniDesk

## 通知与审计

- 应用失败时,管理员收到通知(邮件 + 站内)
- 详细调用日志在「系统设置 → 调用审计」中保留 90 天

## 离线与内网

- Dify 服务可与 OmniDesk 一同部署在内网(详见技术手册 § 33 RAGFlow 类似章节)
- 必须用相同的 SSO 配置,否则鉴权失败

## 常见问题

- **应用无响应**:先在 Dify 控制台测试,排除 Dify 端问题后,查看「应用管理 → 状态」
- **无法访问特定应用**:检查角色权限,管理员在控制面板的「快捷外链」可配置可见性
