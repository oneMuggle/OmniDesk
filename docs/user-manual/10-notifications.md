# 通知中心

> 路径: `/notifications`

通知中心汇集来自各模块的所有站内通知,以及邮件 / Webhook 的发送状态。

## 通知类型

| 类型 | 触发场景 | 默认推送通道 |
|------|---------|--------------|
| 排班变更 | 排班调整、提醒 | 站内 + 邮件 |
| 公告 | 公告发布 | 站内 + 邮件(紧急时) |
| 备忘提醒 | 备忘到期、自定义提醒 | 站内 |
| 项目更新 | 任务指派、里程碑到达 | 站内 + 邮件 |
| 合规问题 | 到期提醒、责任分派 | 站内 + 邮件 + Webhook |
| 系统通知 | 平台维护、安全告警、登录异常 | 站内 + 邮件 |
| 智能助手 | 每日晨报、待办推荐 | 站内 |
| 交流 | @提及、被回复 | 站内 |

## 主要功能

### 1. 查看与筛选
- 顶部分类标签页: 全部 / 未读 / @我 / 已归档
- 类型筛选 + 时间范围筛选
- 关键词搜索(标题 + 摘要)

### 2. 标记与归档
- 单条点击自动标为已读
- 批量操作: 全部标已读、批量归档、批量删除
- 归档通知不在"全部"中出现,但可在「已归档」标签页找到

### 3. 通知偏好
- 在「个人资料 → 通知偏好」调整: 每类通知的通道开关
- 邮件摘要频率: 实时 / 每日 / 关闭
- Webhook 接收: 仅管理员和配置人员可设置

## 通知的"重要程度"

| 等级 | 视觉 | 推送策略 |
|------|------|---------|
| P0 紧急 | 红色顶置 | 站内立即 + 邮件立即 |
| P1 重要 | 橙色顶置 | 站内立即 + 邮件每日汇总 |
| P2 一般 | 默认灰色 | 仅站内 |

## 离线与内网

- 所有通知均存在数据库,持久化(不丢)
- 邮件渠道在断网 / 无 DNS 时会重试(最多 3 次)

## 隐私与审计

- 已读 / 未读 / 删除均留痕
- 删除通知会进入"已删除"(30 天内可恢复)
- 管理员的"系统通知"特权可见所有用户的告警类通知

## 常见操作提示

- 想看"我被提了什么": 进入通知中心 → `@我`
- 想屏蔽某类通知: 「个人资料 → 通知偏好」单类关闭
- 漏看邮件: 看通知中心的"邮件发送失败"标签页,可一键重发

## 最近改进（2026-07 P0 批次）

### 顶部 NotificationBell（铃铛）

所有页面顶部右上角现在挂载一个**铃铛图标**(NotificationBell 组件),未读时显示红色数字角标,5 秒轮询一次:

- **数字 ≤ 9:** 显示具体数字
- **数字 ≥ 10:** 显示 `9+`
- **点击铃铛:** 展开下拉列表,显示最近 10 条通知;点击单条跳转对应模块

> 历史实现 NotificationBell 组件存在但未实际挂载,2026-07 批次挂入 Sidebar.jsx。同时 `EventsPage`(原是空壳)已实接 API,显示日历/事件列表。

### 新通知类型一览

| 类型 | 模块 | 说明 |
|---|---|---|
| `paperless_down` | paperless | 文档存储服务不可用时通知 admin |
| `paperless_recovered` | paperless | 服务恢复时通知 admin |
| `calibration_reminder` | sensor | 传感器校准即将到期 |
| `compliance_due` | project | 合规事项已逾期 / 待办 |

所有通知均带 `dedupe_key`,**24 小时内同 key 通知只会产生一条**(合并历史未读条目)。
