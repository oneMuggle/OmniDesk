# 合规追踪

> 路径: `/compliance`

把所有需要周期性或条件性满足的合规事项集中管理,确保组织始终处于审计可追溯状态。

## 合规事项分类

| 类别 | 示例 | 到期频率 |
|------|------|----------|
| 资质证照 | 辐射安全许可证、实验室认可证书 | 年检 |
| 人员资质 | 操作证、培训记录 | 月度/年度 |
| 设备校准 | 仪器校准、计量检定 | 季度/半年 |
| 体系文件 | 体系手册修订、文件归档 | 半年/年 |
| 法规跟踪 | 新法规识别、影响评估 | 持续 |

## 事项状态

| 状态 | 含义 |
|------|------|
| 待生效 | 已创建尚未到生效日 |
| 在效 | 当前有效期内 |
| 即将到期 | ≤ 30 天到期,红色告警 |
| 已过期 | 已过有效期,需立即续期 |
| 已续期 | 新一轮办理完成 |

## 主要功能

### 自动关联
- 「试验管理」中勾选的合规要求会自动生成对应追踪项
- 「设备管理」的校准计划自动同步
- 「人员管理」的资质到期前 60/30/7 天提醒

### 续期工作流
1. 到期前由责任人新建续期任务
2. 上传新证据(证书、报告)
3. 合规员审核通过后自动归档旧版本
4. 系统生成新的到期日,持续追踪

### 审计导出
- 一键导出「合规有效性报表」(PDF / Excel)
- 包含:所有在效、即将到期、已过期事项的时间线
- 审计时可按时间范围、类别、责任人生成

## 通知策略

- 站内通知 + 邮件双通道
- 即将到期前 30 / 14 / 7 / 1 天通知责任人
- 过期后通知责任人 + 直接上级 + 合规员

## 权限

- 合规员:查看全部、负责审核
- 各部门负责人:负责本部门合规事项
- 管理员:全权
