# 设备管理

> 路径: `/equipment`

统一管理实验室内所有仪器设备的基本信息、校准计划、维护记录与占用情况。

## 设备台账

| 字段 | 说明 |
|------|------|
| 设备编号 | 系统自动生成,不可编辑 |
| 名称 / 型号 | 支持中英文 |
| 位置 | 实验室 → 房间 → 工位 |
| 购置日期 | 影响质保与折旧提醒 |
| 责任人 | 设备主负责人 |
| 状态 | 在用 / 闲置 / 维修 / 报废 |

## 主要功能

### 1. 校准计划
- 创建定期校准任务(如每季度、每半年)
- 校准到期前 14 天通知责任人
- 校准记录自动写入设备历史,可在文档库关联校准证书原件

### 2. 占用管理
- 与「试验管理」联动:试验阶段可占用设备并锁定时间窗
- 占用冲突自动告警
- 解除占用需负责人或管理员操作

### 3. 维护记录
- 故障、维修、保养三类记录
- 维修期间设备状态自动置为「维修」,不可被试验占用
- 可上传维修单、发票等附件到文档库

### 4. 与传感器关联
- 设备上挂载的传感器会自动出现在「传感器管理」列表
- 传感器读数异常时,会同步通知设备责任人

## 权限

| 角色 | 可操作 |
|------|--------|
| 设备责任人 | 维护、查看校准、上传记录 |
| 实验室管理员 | 全部设备增删改 |
| 普通用户 | 仅查看与预约占用 |

## 移动端

- 支持扫码查看设备详情(QR 贴在设备外壳)
- 在现场可快速发起「维修」工单,带位置定位
