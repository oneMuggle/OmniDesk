# RAGFlow 聊天

> 路径: `/ragflow-chat`

RAGFlow 是一个开源的 RAG(检索增强生成)引擎。OmniDesk 把它的"对话"能力封装为聊天页面,适合做"基于自有知识库的问答"。

## 什么是 RAGFlow 聊天

- 把企业内部文档(制度、流程、技术规范)交给 RAGFlow 索引
- 用户提问时,RAGFlow 自动从相关文档检索片段 + 用 LLM 合成回答
- 答案带可点击的引用(原文链接 + 段落高亮)

## 主要操作

### 选择知识库
- 进入聊天页面后,从顶部下拉选择「数据集」(Dataset)
- 多个数据集可叠加(适合"先看制度,再看案例")

### 对话
- 提问支持自然语言,无需写关键词
- 流式输出,中间可中途补充指令
- 每条回答下方标注「引用文档」,点击展开原文

### 反馈
- 每条回答可点 👍 / 👎
- 👎 会提交人工复审,管理员在 RAGFlow 后台可看到错误归类
- 高频反馈会触发"RAGFlow → 文档质量报告"

## 知识库维护(管理员)

知识库的构建在 RAGFlow 控制台完成:
1. 上传文档(PDF/DOCX/MD/TXT)
2. 解析 + 分块(自动或人工切分)
3. 选择 Embedding 模型(默认 BAAI/bge)
4. 发布后即可在 OmniDesk 聊天页面看到

OmniDesk 仅作为调用入口,详情见 [技术手册 § 33](../technical/33-ragflow-integration.md)。

## 离线与内网

- RAGFlow 与 OmniDesk 部署在同一内网,通过 HTTP API 通信
- 所有 Embedding 与 LLM 调用均在本地,数据不出网

## 注意事项

- 知识库质量决定回答质量:文档 OCR/分块质量差时,回答会出现"幻觉"
- 推荐使用结构化、版本明确的文档(避免扫描件、低分辨率图片)
- 大型文档(>100MB)请先在 RAGFlow 端拆分
